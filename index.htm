BOX MODEL

Texto

Content (conteudo)

Define a largura da caixa (salva elementos de blocos)

Padding (preenchimento)

separa o conteudo das bordas da caixa. É a margem interna

width (largura)

A largura total caixa, por padrão é o somatório do conteúdo + padding (left/right) + border (left/right)

Height (Altura)

A altura total da caixa, por padrão é o somatório do conteúdo + padding (top/buttom) + boder (top/buttom)
